# Wayfinder

A single-file study companion for one primary-school student on a **rotating
timetable**: a live class schedule, flashcards, quizzes, a Growth Zone, a focus
timer, a tutor, and XP/streaks/badges.

Same engine as [Ad Astra](https://github.com/ortizzle/ad-astra), rebuilt around a
week that changes shape day to day.

The student's name, school and teachers are **not** in this repository — they are
entered once in the grown-up settings and travel with the private Gist.

See `CLAUDE.md` for what differs from Ad Astra.
